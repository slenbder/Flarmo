## [0.5.0] - 2026-03-24

### Added
- ✅ Ядро системы уведомлений
  - `NotificationService` для управления уведомлениями
  - `NotificationPlanner` для планирования будущих уведомлений
  - `NotificationRegistry` для отслеживания активных уведомлений
  - `NotificationFactory` для создания уведомлений
- ✅ Планировщик повторений (`RecurrenceCalculator`)
  - Поддержка oneTime (разовых будильников)
  - Поддержка weekdays (недельных расписаний)
  - Поддержка shiftPattern (сменных графиков)
  - Поддержка customDates (произвольных дат)
- ✅ Система персистентности
  - `FileScheduleRepository` для сохранения в JSON
  - Thread-safe операции через DispatchQueue
  - Combine stream для отслеживания изменений
- ✅ Модели данных (`ModelsV2.swift`)
  - `Schedule` с поддержкой всех типов расписаний
  - `ScheduleType` enum (oneTime, weekdays, shiftPattern, customDates)
  - `TimeOfDay`, `Weekday` вспомогательные типы
- ✅ UI для разовых будильников
  - `EditOneTimeScheduleView` с полной функциональностью
  - Цветовой пикер
  - Селектор даты и времени
- ✅ Список расписаний
  - `ScheduleListView` для отображения всех будильников
  - Поддержка включения/выключения
  - Навигация на экраны редактирования
- ✅ Миграция данных
  - `MigrationV1toV2` для миграции со старой версии
- ✅ Архитектура
  - MVVM паттерн
  - Repository Pattern для data layer
  - Combine для реактивных потоков
- ✅ Инфраструктура
  - `AppBootstrap` для инициализации
  - `AppLifecycle` для управления жизненным циклом

### Known Issues
- ⚠️ Выбор мелодии — только заглушка (toneId)
- ⚠️ Snooze зафиксирован на 60 секунд (должно быть 5-10 минут)
- ⚠️ Нет UI для shiftPattern, weekdays, customDates (логика есть)
- ⚠️ Отсутствуют тесты
- ⚠️ `ReadonlyScheduleView` — заглушка для типов без UI
