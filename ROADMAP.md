## 📊 Текущее состояние

### ✅ Готово
- [x] Ядро уведомлений (NotificationService, NotificationPlanner, NotificationRegistry)
- [x] Планировщик повторений (RecurrenceCalculator)

## 📝 Заметки

- Весь новый UI на SwiftUI
- Следовать паттерну MVVM + Repository
- Все коммиты в Conventional Commits формате
- После каждого изменения — сборка и проверка
- НИКОГДА не удалять DerivedData (работаем с Claude Code)
- Все строки UI на русском языке
- Обязательно тестирование на реальном устройстве перед релизом
